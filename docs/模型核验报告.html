方法说明与局限

  • 权威基准：元宝搜索 VR 卡（Mode=1），数据来自携程车次库，含始发/终到/逐站到发时刻。
  • 模型侧：DeepSeek / Kimi 网页版，均为默认开启联网搜索的真实回答，原文与整页存档保留。
  • 比对规则：先按车次号精确匹配，剔除相似车次（G27 与 G2701）造成的假错；模型给的是发车时刻则比发车，否则比到站。
  • 局限：① 模型回答会受当日检索结果影响，换时间可能变化；② 部分冷门车次官方库未覆盖，只能判"存疑"；③ 网页审计的"不符"基于摘要中的时间/线路声明，未抓取全文。
